# EXP-008-net1-clean-labels: Experiment plan
- **Status:** APPROVED (2026-11-22, 연구자 "A안으로 돌려놓고").
- **Associated idea (folder):** IDEA-001-imitate-verified-gt
- **Question:** Net1 이 새 물체에서 빈도 규칙 수준에 머무는 원인이 정답 노이즈(원인 2)인가, 입력 정보 부족(원인 3)인가 (EXP-007 에서 목표 모양은 배제).
- **Data:** 학습 6.5% 부분집합 6,283 파지(물체 해시 frac 0.065, EXP-005 규칙) + 검증 파지 4,648 전부.
  새 정답 = B1 탐색(후보 64/24, two_stage 채점: 거친 단계 α → 다듬기·확정 ρ0 정점 64), 시드 0·1 를 레코드마다 ρ0 최댓값으로 합침, 조건표 생략,
  게이트 = 법선 힘 제어 + 외란별 최적 배분, N≥3 전 레코드 판정.
- **Training:** 같은 6.5% 부분집합에서 Net1 v1.1 설정 30 에폭, seed 0, 목표 모양 prop(기존). (가) 지금 정답, (나) 새 정답. 필요하면 set95 도.
- **Primary metric (사전 고정):** 검증 파지, 후보 2개 이상, 0.95배 기준 정확도(새 정답으로 채점). 비교 = 새 정답 기준 빈도 규칙(6.5% 부분집합 1등 빈도)과 무작위.
- **Reading rule:** (나) 가 빈도 규칙보다 3%p 이상 높으면 원인 2 (전량 재생성 가치 있음). 1%p 이내면 원인 3 (재생성 전에 입력을 바꿔야 함). 그 사이는 연구자 판단.
- **Budget:** 생성 약 9.6시간 + 합치기 + 게이트 약 1시간 + 학습 각 2분. GPU 1장.
- **Caveats:** 시드 1개 학습. 6.5% 는 25% 와 지금 정답 기준 성능 차이 0.1~1%p (사전 확인). (가)는 지금 정답으로 채점하면 정답 기준이 달라지므로, 두 모델 모두 새 정답으로 채점한다.
