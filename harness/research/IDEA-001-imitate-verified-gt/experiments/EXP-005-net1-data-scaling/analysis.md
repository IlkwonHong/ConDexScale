# EXP-005-net1-data-scaling: Analysis
- **Plan and immutable evaluation criteria:** `plan.md`. 주 지표 = 최고 에폭(top-1 N3·N4 평균 최대) 의 top-1 N=3, N=4, 두 시드 평균. 50%→100% 상승 ≥ 2%p 이고 시드 차보다 크면 "데이터 부족", < 1%p 면 "평평", 그 사이는 연구자 판단.
- **Runs analyzed:** runs/run-001 ~ (세션 중단으로 일부 재실행. 최종 체크포인트는 `checkpoints/exp005_f{0.25,0.5,1.0}_s{0,1}/`, 각 30에폭 완주). 코드 커밋 aa81591(학습 옵션), 작업 공간 worktree-gt-v2-pilot.

- **Verdict (사전 기준):** 50%→100% 상승 N3 +0.57%p → "평평". N4 +1.11%p → 연구자 판단 구간. 25%→100% (4배) 상승도 N3 +1.17%p, N4 +1.41%p 로 시드 간 차이(최대 약 1.0%p)와 같은 크기.
- **Supported claims:** 지금 GT·모델·학습 설정에서 학습 파지 수는 Net1 top-1 의 주된 한계가 아니다. 파지 수를 늘려 얻을 수 있는 이득은 4배에 1~1.5%p 수준이다.
- **Unsupported / uncertainty:** 시드 2개뿐이라 1%p 안팎의 차이는 우연과 잘 구분되지 않는다. 라벨(GT)을 ρ·3시드로 바꾸면 라벨 노이즈가 줄어 데이터 효율이 달라질 수 있다(이 시험은 지금 α GT 기준). 물체 다양성(물체 수)과 파지 수를 따로 떼어 보지 않았다(부분집합이 물체 단위라 둘이 함께 줄었다).
- **Protocol deviations:** plan.md 의 비교 기준값(v1.1 top-1 N3 46.5%, N4 41.4%)은 2026-07-29 지표 수정 이전 값이었다. 수정된 지표의 v1.1 값은 39.5% / 37.3% (PROGRESS.md) 이고, 이번 100% 결과(39.7% / 36.8%)와 일치한다. 세션 중단으로 실행이 세 번 끊겨 재시작했고, 끝나지 않은 실행은 처음부터 다시 돌렸다.
- **Implication for GT v2 (연구자 결정 사항):** 재생성 규모를 늘릴 근거는 약하다. 지금 규모(약 10만 파지) 또는 그보다 적게 만들어도 된다.
